# 1280 × 720 PNG Maker

画像を幅1280pxへリサイズし、高さ720pxへ切り抜いてPNG保存する、インストール不要のブラウザツールです。

**[https://nexustide400.github.io/image-1280x720/](https://nexustide400.github.io/image-1280x720/)**

## 特徴

- 縦横比を保ったまま幅を1280pxへ変更
- 720pxを超えた高さを切り抜き
- スライダーで上寄せ・中央・下寄せを調整
- 高さが720px未満の場合は上下を透明で補完
- PNG形式で保存
- 画像のアップロードなし
- 外部ライブラリ・ビルド作業なし
- PC・スマートフォン対応

## 使い方

1. 画像を画面へドラッグ＆ドロップするか、「画像を選ぶ」を押します。
2. 必要に応じて切り抜き位置を調整します。
3. 「PNGを保存」を押します。

画像処理はHTML Canvasを使い、すべて利用者のブラウザ内で実行されます。画像がサーバーへ送信されることはありません。

## ローカルで使う

`index.html`をブラウザで開くだけで使用できます。インストールやWebサーバーは不要です。

## 技術構成

- HTML
- CSS
- JavaScript
- Canvas API
- Blob API

単一の`index.html`だけで動作します。

## 処理仕様

1. 元画像の横幅を1280pxに合わせる倍率を計算します。
2. 縦横比を維持した変換後の高さを計算します。
3. 高さが720px以上なら、指定位置に応じて余剰部分を切り抜きます。
4. 高さが720px未満なら、画像を上下中央へ配置して透明部分で補います。
5. 1280 × 720pxのPNGを生成します。

## 対応ブラウザ
